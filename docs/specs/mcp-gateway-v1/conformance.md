# MCP gateway conformance cases

1. Verify direct routing selects only the named upstream; aggregate routing
   namespaces equivalent skills from different upstreams without collision.
2. Reject an unlisted extension method without forwarding it upstream.
3. A modern discovery timeout eligible for fallback may use legacy initialize;
   malformed or uncorrelated responses and modern security rejection fail closed.
4. An unsupported task or input-required tool result becomes an explicit error.
5. On SSE, the first final result or error terminates the stream; a client
   distinguishes JSON-RPC errors from HTTP transport failure.
6. Skill listing and cached bytes do not grant source access or skill consent.
