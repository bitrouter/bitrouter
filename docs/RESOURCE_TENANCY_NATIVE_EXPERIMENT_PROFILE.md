# Authenticated local native experiment profile

This additive local Rust profile uses the existing authenticated NativeSession,
retained native Generation route, Core preparing ACK, Service writer, receipt
Registry and trajectory/Eval engine. The local embedding surface includes
NativeSession::experiment_cohort(model, evidence_root), returning the existing
CohortAssessment, plus review_run, submit_assessment, retract_assessment and
assess_run for the current completed native run. These methods add no HTTP, CLI,
SDK, permission or authority constructor.
The existing protected Eval freeze transport supplies the root; the library
example owned_native_experiment shows the actual run, freeze, local read and close.

The initial profile requires core+harness on the existing supported Unix local
host. A fixed retained R1 must select a static-credential, nonstream policy route
in Explore mode, one valid signed active route experiment and an enabled progress
guard protecting both champion and challenger. The experimental route cannot
also require OAuth, input counting or CoreChoice. It may retain an explicitly
qualified static Generation evaluator for assess_run(checkpoint, expected_revision);
that evaluator is invoked only by this explicit action, never automatically by
run completion. Both subject and evaluator credentials must be static. Ambient
evaluator discovery, recursive evaluation and evaluator counting/OAuth are refused.
Other routes in the source retain their independent profiles. Compiler-v1 bytes,
Legacy fences and advertised false capabilities remain unchanged.

One actual Core root run is one immutable assignment unit and bound Episode.
Child, wakeup and followup model steps inherit that unit; a new explicit root
gets a new unit. A caller correlation or forged workflow label cannot enroll it.
The H writer checks the current authenticated authority, immutable source and
whole original native journal before the actual provider path. Installation,
tenant and experiment identify the cumulative counter across principals, key
rotation and revision activation. Durable acceptance is not refunded, redrawn or
silently substituted with the champion when the challenger cap is exhausted.
Admission reserves even a later nonmatching projection; only genuine matching
producer evidence is observed by the cohort.

Every execution keeps its original 035 receipt. The receipt transaction, original
032 terminal/Eval/outbox transaction and original native journal ACK transaction
advance their exact private edges atomically with their own facts and one shared
operation budget. A cancelled waiter does not release SQL or native command
ownership. Cleanup remains authorized after revocation, while new effects and
sensitive cohort delivery require current authority and the original grant
ceilings. Unconfirmed commit/process/provider work remains fenced under the
existing owner; no elapsed time, new epoch or file lease proves remote completion.
Pending experiment records retain the common startup fence. Crash adoption is
outside this profile until its exact stopped-owner proof is qualified.

Storage limits are cumulative: at most 1,024 accepted units per experiment,
128 steps per unit, 8 KiB per private record and 1 MiB of step records per unit.
Each writer participant and the local cohort read share the existing
4,096-row/32 MiB operation budget, including all snapshot, Eval, original receipt
and Episode closure reads. The cohort retains its five-second work deadline.
A whole tenant root may
therefore exceed the report limit well before it reaches 1,024 results. New work
must fit its all-pending Core/journal/ACK allowance before effects; ordinary
NativeSession limits are unchanged. Explicit smaller run limits can leave more
room within this profile. New experimental workspace and verification invocations
freeze at most 64 KiB of artifact bodies per outcome/status, intersected with
the existing quota share. All five first outcome/status slots remain reserved.
This does not reduce the manifest quota or re-limit admitted/restored commands;
ordinary native and Legacy allocation policy remains unchanged. Retention does not delete unresolved rows to create
capacity. Large or contradictory closures fail closed before unbounded reads.

The report uses one stable actor transaction and validates the actual immutable
root and producer closure; it neither rereads a different snapshot nor trusts
Generic submissions copying experiment labels. It requires current tenant-wide
resource.read within both original credential and binding ceilings. Existing
built-in operational results are Inconclusive: observed control/challenger counts
can be positive while the verdict remains InsufficientEvidence. Provider success
is not conclusive task quality or permission to promote a policy. An explicit
Human rubric or completed paid assessment can contribute separately checked
quality from the exact current native source and effective head. The original
operational projection and frozen root remain unchanged. Human corrections use
head CAS; an awaited paid result cannot replace a newer Human head.

Paid acceptance pins the actual completed source under the original native
host and reserves its terminal history before dispatch. Its configuration revision
counts accepted logical jobs cumulatively; cancellation, retraction and restart
do not refund that count. Logical identity uses the immutable configuration,
completed source, evaluator and quality-input digest. The expected assessment
revision is a selection CAS, so changing that revision alone does not buy another
judgement or restore a paid result withdrawn by a Human. Repeating an accepted
logical job retains its original result without another provider request. A new
completed run is a distinct logical job and must fit the same revision's remaining
allowance. Known terminal/output facts survive lost selection.
Stopped unfinished recovery additionally requires the actual local close ACK and
exact old Registry stop-set under the existing StartupOwner. It never resends the
judge request; missing terminal evidence remains Unknown/Interrupted. Historical
terminal integrity reads do not grant access to judge an old run.

Complete economics attribution, experimental intersections with Choice/OAuth/
counting, owned block experiments, full learner promotion and fault coverage,
scheduling and retention/maintenance remain separate all-core obligations. This profile makes no M2/M3 or all-core completion
claim. Runtime qualification is required before enabling any production flag.
