# UX design references

Every document in this directory is a retained design record, including
historical first-party UI work and unshipped proposals. None is current product
or API documentation. Their descriptions of removed interfaces are historical
and do not override current [CLI behavior](../CLI.md) or the
[CLI and skills implementation guide](../development/cli-and-skills.md).
Maintain useful interaction requirements here; implementation ownership belongs
in [development guides](../development/README.md), and serialized formats belong
in their [canonical specifications](../specs/README.md).
