## Summary

This study compares a pooled fixed `gpt-5.6-sol` baseline, two BitRouter routing
configurations, and a five-replicate fixed-proportion random-routing control.
It contains 1,691 raw Harbor trials across 89 Terminal-Bench 2.1 tasks. The
primary comparison uses the strict 80-task intersection for which every
required replicate in B1–B4, G1, G3, and R1–R5 completed without a top-level
Harbor exception.

G1 is the strongest observed cost/quality result. Against the four-replicate
pooled GPT baseline, it reduced frozen-price nominal API cost per accepted
valid-path trial by 40.93%, from $0.830123 to $0.490317. Valid-cases reward was
81.25% versus 81.5625% for the baseline, an observed difference of −0.3125
percentage points.

The pooled random control used the same model set as G1 but reached 76.50%
valid-cases reward at $0.552670 per trial. G3 achieved nearly the same cost as
G1 but only 75.50% reward. These observations show that the lower-cost model
pool alone did not reproduce G1's result; they do not by themselves establish
statistical equivalence, causal credit assignment, or online-learning gains.

## Cost Scope

Cost is the frozen-price nominal API cost of accepted valid-path requests,
aggregated per common-valid trial. It is suitable for comparing the routing
configurations under the study's fixed accounting rules. It is not:

- provider billing or the cash cost of a subscription;
- total workflow cost including failed or excluded paths, evaluation, and
  infrastructure;
- a latency result; or
- a claim that the same relative saving transfers unchanged to another model
  pool, price schedule, cache profile, or workload.

The primary G1 result uses provider-reported GPT usage plus exact request-ID
matches to a bounded BitRouter Cloud export for Kimi and DeepSeek usage. Only
sanitized derived rows are published. G3's DeepSeek Pro usage is marked
`estimated` where authoritative upstream usage was unavailable, so G3 cost has
a weaker evidence quality than G1.

## Evidence and Reproducibility

The public release includes three evidence layers for every group:

1. Raw Harbor `result.json` and `trajectory.json` files, which remain
   authoritative for native reward and exceptions.
2. Frozen BitRouter SQLite evidence bundles. R1 and R2 originated on a shared
   router volume, so the R2 database is cumulative; hashed request joins, not
   bundle membership alone, provide accepted-path attribution.
3. Privacy-preserving usage reconstruction with SHA-256-hashed request IDs and
   row-level source and quality labels.

The release also provides Parquet tables for group definitions, trials, trace
steps, SQLite requests, production usage, request joins, trial usage, group
summaries, the common-valid set, and SQLite audits. Pipeline scripts rebuild
and validate the normalized tables; the raw evidence remains authoritative.
The publication-verification summary reports `pass: true`, all completed group
evidence checks passing, public visibility, no provider credentials uploaded,
and no raw production database export uploaded.

## Limitations

- This is a research artifact, not an official Terminal-Bench submission.
- The primary valid-case analysis conditions on the strict intersection of 80
  tasks. Nine canonical tasks were excluded because at least one required
  replicate had a top-level exception; full-denominator Harbor reward is shown
  separately.
- The reported reward differences are descriptive. The release does not claim
  a confidence interval, formal non-inferiority result, or statistical
  equivalence between G1 and the baseline.
- Cost covers accepted valid-path API usage at frozen prices, not provider
  billing or complete execution, evaluation, and infrastructure cost.
- G3 includes estimated DeepSeek Pro usage where authoritative upstream usage
  was unavailable. The headline G1 result does not rely on that estimate.
- Random runs used concurrency 6 while baseline and routed groups used
  concurrency 4. No latency comparison is made.
- The result is specific to the frozen model pools, efforts, routing policies,
  benchmark revision, and price schedule.

## Conclusion

Within the frozen study, G1 preserved the baseline's observed valid-cases
reward to within 0.31 percentage points while reducing nominal accepted
valid-path cost per trial by 40.93%. It also exceeded the pooled random
control's reward by 4.75 percentage points at a lower nominal cost. G3's lower
reward at similar cost shows that cheap routing alone is insufficient.

The defensible conclusion is that this G1 routing configuration produced a
substantially better observed cost/quality point than the fixed-proportion
random control and a near-baseline observed reward at materially lower nominal
valid-path cost. Formal quality equivalence and generalization remain open.
